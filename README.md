# Business Syndicate — сайт мастермайнда

Премиальный лендинг мастермайнда Рафаэля Салманова (Нижний Новгород).
Статический сайт: HTML + CSS + vanilla JS. Без сборки — открывается и деплоится как есть.

## Быстрый старт
Открыть `index.html` в браузере. Для полных анимаций нужен интернет (CDN: GSAP, ScrollTrigger, Lenis, шрифт Inter). Без сети сайт работает в упрощённом виде (graceful degradation).

## Структура
```
index.html            — вся разметка (7 «глав»-секций), SEO, Schema.org JSON-LD
css/
  variables.css       — ВСЕ дизайн-токены: цвета, шрифты, отступы, z-index
  reset.css           — reset + focus-стили
  typography.css      — типографика
  components.css      — кнопки, карточки, лоадер, модалки, форма, лайтбокс, зерно
  sections.css        — стили секций-глав
  animations.css      — keyframes + prefers-reduced-motion
  responsive.css      — брейкпоинты: 4K / laptop / tablet / mobile
js/
  config.js           — ★ ГЛАВНЫЙ КОНФИГ (см. ниже)
  app.js              — подстановка конфига в DOM
  smoothScroll.js     — Lenis + синк со ScrollTrigger
  cursor.js           — магнитные кнопки (кастомный курсор удалён по решению заказчика)
  particles.js        — угли в hero (canvas)
  network.js          — ★ интерактивная инсталляция «Связи решают»:
                        физика ambient + постановочные твины сборки слов,
                        spatial hashing, машина состояний, импульсы по связям
  hero.js             — посимвольный заголовок, параллакс, камера при скролле
  animations.js       — GSAP-режиссура всех секций
  countdown.js        — таймер с фазами (1 день = 1 этап) + счётчик мест
  tilt.js             — 3D-наклон карточек + световое пятно
  modal.js            — модалки тарифов (тексты кругов внутри)
  form.js             — валидация, отправка (сейчас → Telegram)
  gallery.js          — лайтбокс галереи
  lazyload.js         — ленивые img/video, видеоотзывы по клику
assets/
  images/             — превью видеоотзывов (webp)
  video/              — сжатые видеоотзывы (mp4 1280p)
robots.txt, sitemap.xml
```

## ★ Конфиг (js/config.js)
Всё главное меняется в одном месте:
- `clubName` — название клуба (бэкдор: идёт суд за товарный знак, название может смениться — правится одной строкой);
- `eventDate` — дата мастермайнда (сейчас заглушка 2026-08-01);
- `seatsTotal` / `seatsLeft` — счётчик мест (обновлять руками);
- `links.tgApply` — куда уходит заявка;
- `countdown.daily` / `phases` — тексты таймера по дням и фазам;
- `anim.*` — все параметры анимаций.

## Версионирование кэша
Все css/js подключены с `?v=3`. При правках файлов увеличить до `?v=4` (глобальный replace в index.html).

## Дизайн-принципы (не ломать)
- Палитра строго: чёрный #0A0A0C / графит / белый / красный #FA1E32.
- Анимации только transform/opacity (GPU), никаких top/left/width.
- Все движения имеют смысл, сайт = «фильм» из 7 глав.
- Антитезы в текстах запрещены (требование заказчика).
- liquid glass: навигация, блок таймера, модалки, поля формы — сохранять стиль.
