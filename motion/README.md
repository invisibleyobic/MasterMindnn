# Ролик «Мастермайнд Рафаэля Салманова» — графика кодом

- `mastermind.html` — вся анимация (GSAP, одна шкала времени). Предпросмотр в браузере: `motion/mastermind.html?play` (окно 16:9 или 9:16 — раскладка подстраивается).
- `render.js` — покадровый рендер в MP4: `python3 -m http.server 8765` из корня, затем `node motion/render.js 16x9` и `node motion/render.js 9x16`. Готовые файлы — `motion/out/`.
- `SCRIPT_v1.md` — текст для ElevenLabs и раскадровка (утверждено 30.10: «декабрь» без даты, «личная работа с Рафаэлем», цены 10/30/50).

## Подгонка под озвучку
Все сцены стартуют по объекту `T` в начале скрипта (секунды):
`s1` хук · `s2` Рафаэль · `s3` сеть 3 500 → 35 000 · `s4` декабрь · `s5` три круга (`c2`, `c3` — вход «Медиа» и «VIP») · `s6` близкий круг · `s7` финал · `end` длина.
Получив готовую озвучку: снять тайминги фраз (ffmpeg silencedetect), подставить в `T`, перерендерить оба формата, наложить звук.
